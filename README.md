# Diplom_2 — API-тесты Stellar Burgers


## Описание проекта
Автотесты для API сервиса **Stellar Burgers**.


В проекте покрыты тестами основные ручки:
- создание пользователя
- авторизация пользователя
- создание заказа


Тесты написаны на:
- `pytest`
- `requests`
- `allure-pytest`

## Описание файлов


### `api_methods/`
Папка с методами для работы с API.


- `user_methods.py` — методы для ручек пользователя:
  - создание пользователя
  - авторизация пользователя
  - удаление пользователя
- `order_methods.py` — методы для ручек заказов:
  - получение данных об ингредиентах
  - создание заказа


### `tests/`
Папка с автотестами.


- `test_create_user.py` — тесты создания пользователя
- `test_login_user.py` — тесты авторизации пользователя
- `test_create_order.py` — тесты создания заказа


### `conftest.py`
Фикстуры для подготовки и очистки тестовых данных.


### `helpers.py`
Вспомогательные функции для генерации тестовых данных.


### `data.py`
Тестовые данные и ожидаемые значения для проверок.


### `urls.py`
Константы с URL и endpoint тестируемых ручек.

## Покрытые сценарии


### Создание пользователя
- создание уникального пользователя
- ошибка при создании уже существующего пользователя
- ошибка при отсутствии одного из обязательных полей


### Авторизация пользователя
- успешная авторизация существующего пользователя
- ошибка авторизации с неверным логином
- ошибка авторизации с неверным паролем


### Создание заказа
- создание заказа с ингредиентами и авторизацией
- создание заказа с ингредиентами без авторизации
- создание заказа без ингредиентов с авторизацией
- создание заказа без ингредиентов без авторизации
- создание заказа с невалидным хешем ингредиента с авторизацией
- создание заказа с невалидным хешем ингредиента без авторизации

## Установка зависимостей


Создать и активировать виртуальное окружение.


### Windows
```bash
py -m venv .venv
.\.venv\Scripts\activate
```


Установить зависимости:


```bash
py -m pip install pytest requests allure-pytest
```


---


## Запуск тестов


### Запуск всех тестов
```bash
pytest
```


### Запуск папки с тестами
```bash
pytest tests
```


---


## Allure-отчёт


### Сгенерировать результаты Allure
```bash
pytest --alluredir=allure_results
```


### Открыть отчёт
```bash
allure serve allure_results
```


---


## Особенности реализации
- Для генерации тестовых данных используется случайный `email`, `password` и `name`.
- Удаление созданного пользователя выполняется в фикстурах после завершения теста.
- Для создания заказа валидный `_id` ингредиента получается через отдельный запрос к 
ручке ингредиентов.
- В проекте используются `Allure step` и `title` для более наглядного отчёта.
